Introduction

Interlink is a lightweight, minimal mediator library designed specifically for modern .NET applications. It helps decouple your controllers or services from your business logic layer using standard request/response and notification patterns without unnecessary complexity or bloated third-party dependencies.

Installation

Install the library directly via the .NET CLI or via your NuGet Package Manager interface in Visual Studio:

dotnet add package Interlink

Dependency Injection Setup

Register Interlink services seamlessly inside your Program.cs file:

Program.cs
// Register Interlink handlers and mediator instance
builder.Services.AddInterlink(typeof(Program).Assembly);

Requests & Handlers

A request represents a single operation or query that expects a specific return type. Implement IRequest<TResponse> and its corresponding handler.

GetUserQuery.cs
public record GetUserQuery(int Id) : IRequest<UserDto>;

public class GetUserQueryHandler : IRequestHandler<GetUserQuery, UserDto>
{
    public async Task<UserDto> Handle(GetUserQuery request, CancellationToken cancellationToken)
    {
        // Data fetching logic implementation
        return new UserDto(request.Id, "Jane Doe");
    }
}

Notifications & Pub/Sub

Use notifications when multiple handlers need to react to a domain event or system action asynchronously.

UserCreatedNotification.cs
public record UserCreatedNotification(int UserId) : INotification;

public class EmailWelcomeHandler : INotificationHandler<UserCreatedNotification>
{
    public async Task Handle(UserCreatedNotification notification, CancellationToken cancellationToken)
    {
        // Send a welcome email to the newly created user
    }
}
